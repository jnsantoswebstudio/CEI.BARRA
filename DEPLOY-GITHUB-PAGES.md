# Deploy no GitHub Pages

1. Coloque `index.html`, `admin.html`, `site.css`, `site.js`, `admin.css`, `admin.js`, `images/` e `.nojekyll` diretamente na raiz do repositório.
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
3. Branch: `main`. Folder: `/ (root)`.
4. Salve e aguarde o GitHub publicar.

Esta versão foi feita para não exigir build.
